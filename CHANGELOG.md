# Changelog

A record of changes to SAFAD since version 1.4.0 (2026-07-06). For previous
changes, see the [commit
history](https://github.com/SLU-foodsystems/safad/commits/main).

## Version 1.4.0 (2026-07-06)

In preparation for the upcoming release of version 2.0.0, we introduce more
controlled versioning and an explicit changelog to document changes to SAFAD.

### New in this version

- Introduce explicit versioning. Before, we counted the number of commits since
  last major version. Now, we set the version manually in `package.json`. Changes
  are documented in `CHANGELOG.md`.


### Changes to data or file format

No changes to the file format or the underlying data were made.
